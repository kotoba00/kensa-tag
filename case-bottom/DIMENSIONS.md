# 寸法と出典

座標は `build_case.py` の冒頭と同じ。x は左右で中心が 0、y は USB-C 側の端が 0 で前（レンズ側）が +、z は QR Base の底面が 0 で上（画面側）が +。単位は mm。

実測した値は下の「実測した値」の表にある。それ以外は公式資料から読んだか、推定した値。**印刷してのはめ合いはまだ確かめていない。**

## 実測した値（2026-11-03、ノギス）

| 項目 | 値 | 定数 |
|---|---|---|
| QR Base＋AtomS3R の長さと幅 | 48 × 24 | `UNIT_L` `UNIT_W` |
| QR Base の上面 | 17.5（写真でも約 17.7） | `QR_H` |
| AtomS3R が QR Base の上面から飛び出す高さ | 3.5。全高は 21 | `UNIT_H` |
| 底面から USB-C の中心まで | 16 | `USB_Z` |
| 底面から AtomS3R の Grove の中心まで | 10 | `GROVE_ATOM_Z` |
| 後端からリセット中心まで、底面からリセット中心まで | 16.4 / 14 | `RESET_Y` `RESET_Z` |
| リセットがある側 | 左側面（USB-C を手前にして左）。右側面の細長い窓はリセットではない | なし |
| USB-C プラグの幅 | 11 | `USB_PLUG` |
| Grove プラグが差し込み口から出る長さ | 3 | `GROVE_PLUG` |
| 底面からレンズの中心まで | 10.3 | `LENS_Z` |
| AtomS3R の高さ | 12.5（公式は 12.9）。形には使っていない | なし |

## 公式の形状データや写真から推定した値

AtomS3R の開口位置は、[公式の STL](https://github.com/m5stack/M5_Hardware/tree/master/Products/C126_AtomS3R/Structures) を走査して読んだ。STL はケースだけでコネクタが入っていないので、幅と高さは開口からの推定。STL はこのリポジトリに入れていない。

| 項目 | 値 | 根拠 |
|---|---|---|
| レンズの窓 | 下から 6〜15 mm、奥行き 3 mm | 製品写真 |
| RFID2 のアンテナ中心 | Grove 側の端から 32 | 製品写真のシールの中心 |

## 仮に決めた値

| 項目 | 値 | 理由 |
|---|---|---|
| USB-C プラグの厚さと長さ | 7.5 × 25 | 太めの市販品を想定。幅だけ実測。写真のケーブルは約 4 × 14 |
| USB-C の金属部 | 8.4 × 2.6 × 6.5 | USB-C の一般的な寸法 |
| Grove プラグの幅と高さ | 9.6 × 4.8 | 図面のソケットからの推定 |
| AtomS3R 後ろの金色のコイル | 後端から約 0.6 出る | 写真から。足の上半分を y=-1.2 まで下げてよけた |
| RFID2 の裏と本体の底の間 | 2 | 受けレールの高さ。実機では距離を変えて試していない |

## まだ測っていない項目
